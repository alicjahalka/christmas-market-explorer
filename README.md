
# **🎄 Christmas Markets Explorer 2026**

## **Project Overview**

Christmas Markets Explorer is my first Python data analysis project, focused on exploring Christmas markets across Europe in 2026.

The goal of this project is to practice data cleaning, transformation, and analysis using Python and pandas, and to build a simple interactive program for exploring the results.

Technologies Used:

- Python

- pandas

- PyCharm

- CSV files

## **Project Workflow**

### 1. Data Exploration

- Loaded the dataset from a CSV file.

- Examined the dataset structure and column types.

- Identified missing values and checked for duplicates.

### 2. Data Cleaning

- Converted date columns into datetime format.

- Calculated the duration of each Christmas market.

- Saved the cleaned dataset to a new CSV file.

### 3. Data Analysis

- Identified the 10 earliest-opening Christmas markets.

- Found the earliest-opening markets in each country.

- Analyzed the average duration of Christmas markets by country.

- Counted Christmas markets by country and opening month.

- Filtered markets by country, duration, and opening date.

### 4. Interactive Menu

- Created a simple terminal-based program that allows users to:

- View the 10 earliest-opening Christmas markets.

- View the earliest-opening markets by country.

- Find Christmas markets open on a selected date.

- Exit the program.
